Inter normal and italic variable fonts, copied unchanged from Obsidian's packaged
`public/fonts/c504db5c06caaf7cdfba.woff2` and
`public/fonts/01dcbad1bac635f9c9cd.woff2` resources.

Both faces declare weights 100–900. These replace BlockNote's static Latin-only
Inter faces, so the same local font serves Russian and English text and real
italic text. The application uses normal glyphs, without forced stylistic sets.

Inter is distributed under the SIL Open Font License 1.1. The complete notice is
included in the shipped application at `/fonts/OFL-Inter.txt` and in
`public/fonts/OFL-Inter.txt` in the repository. Upstream:
https://github.com/rsms/inter/blob/master/LICENSE.txt

JetBrains Mono normal and italic variable fonts are the unmodified official
version 2.304 from `JetBrains/JetBrainsMono`, `fonts/variable/`. They serve code
and source Markdown, matching the user's pinned choice. Both faces support
weights 100–800. Their complete SIL OFL notice ships at
`/fonts/OFL-JetBrainsMono.txt`.

https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/variable
