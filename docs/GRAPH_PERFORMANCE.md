# Проход по производительности графа — 11 октября 2026

Ветка `codex/graph-modes`, исходная версия `9c3f69d`. Проверялись глобальный граф в двух режимах и локальный WebGL-граф в редакторе. Изменения выполнены в отдельном worktree.

## Что изменилось

- Обычный выбор узла показывает карточку и больше не закрепляет/открепляет его в физике. Это устраняет сброс затухания от простого клика. Команды реального перетаскивания объединяются до частоты отрисовки.
- Позиции, камера, закрепления, фокус, фильтры и параметры сохраняются при переходе между графом и заметкой. Кэш содержит данные; Worker и графические ресурсы освобождаются при выходе. Устоявшаяся раскладка восстанавливается без нового расчёта физики.
- Кэш ссылок переживает переходы между экранами. В парсер передаются только изменившиеся тела Markdown. Изменение текста без изменения ссылок не меняет объект связей. Очередь обновлений сериализована, чтобы поздний ответ не подменял новые данные.
- Изменение метаданных сохраняет существующую модель связей. При изменении рёбер переиспользуются Renderer, текстуры узлов и поток физики; небольшой прогрев начинается из прежних координат. При изменении состава узлов индексы и буферы обновляются с проверкой поколения сообщений.
- Пространственный индекс для мыши хранит числовые ячейки и переиспользует массивы. Перемещение одного узла обновляет одну запись. Границы графа, пути линий, порядок групп и фон миникарты кэшируются.
- В объёмном режиме неподвижные спрайты и линии не подготавливаются повторно при каждом движении камеры. Отфильтрованная жидкая подложка кэшируется; дыхание меняет прозрачность без пересчёта плотности. Во время взаимодействия подложка использует уменьшенное разрешение и затем возвращается к полному качеству; узлы и подписи остаются чёткими.
- Локальный граф больше не имеет постоянно работающего Pixi ticker. Он останавливается после затухания, при скрытии окна и вне области видимости, сохраняя отклик на наведение, масштаб и перемещение.
- Экран графа и объёмный painter загружаются по необходимости. Это убрало около 209 КБ из начального JavaScript chunk.
- Контекстное меню узла больше не закрывается тем же событием, которое его открывает. Закрепления проверены после возврата из заметки.

## Подтверждённые результаты

Хост — Apple M5, macOS 26.6.2. Для измерения использовался локальный dev-стенд с одинаковыми данными и счётчиками. Проверка операций выполнялась на 5000 заметок: 5250 узлов и 15000 связей в объёмном режиме, 5000 узлов и 10000 связей в плоском. Отдельно проверена копия реального vault из 530 Markdown-заметок.

| Операция | До | После |
|---|---|---|
| Изменение метаданных одной заметки | Повторный разбор 5000 документов, два новых потока физики и сотни обновлений расположения | 0 документов, 0 новых потоков, 0 шагов и 0 перерисовок графа для невизуальных метаданных |
| Возврат из заметки | Повторный разбор 5000 документов и запуск раскладки | 0 повторных разборов; один начальный кадр данных без шага физики, восстановлены камера и закрепления |
| Изменение одной связи | Полный пакет тел заметок и пересоздание сцены | Разобран 1 документ; сохранены Renderer и Worker, обновлена геометрия |
| Одиночный клик в устоявшемся графе | Команды pin/unpin могли сбросить затухание | Счётчик кадров физики не изменился; только кадры выбора и карточки |
| Локальный граф после затухания | Счётчик Pixi render продолжал расти | Счётчики render и paint остаются постоянными |
| Начальный JS chunk | 2703,34 КБ, gzip около 837,30 КБ | 2494,55 КБ, gzip 768,04 КБ; экран графа вынесен в отдельный chunk |

Оба режима остаются без отрисовки в покое. Счётчики не измеряют время завершения GPU-команд или расход батареи. В предыдущем движущемся стенде 44–46 кадров/с были также связаны с выбранной частотой Worker около 50 шагов/с; это не доказательство ограничения видеокарты. Поэтому здесь основной результат — устранённая повторная работа и сохранение состояния, а не обещание фиксированного FPS на любом устройстве.

## Проверки

- 32 автоматические проверки: парсер ссылок, кэш с конкурирующими обновлениями, метаданные, пространственный индекс, восстановление Worker, пауза, закрепление и сохранность Markdown. В полном тесте прочитаны все 530 заметок без изменения исходников.
- Ручная проверка в локальном браузере: оба режима, карточки, обычные клики, перемещение, контекстное меню, закрепление, переход и возврат, добавление/удаление узла, изменение одной связи, миникарта и узкий экран.
- TypeScript, production frontend и macOS `.app` собираются. Сохранились прежние предупреждения общего bundle, смешанных динамических импортов и `::highlight`.

Позиции и фильтры сохраняются в пределах текущего запуска приложения. Кэш не сохраняет живую сцену между экранами и не записывает большой массив координат синхронно в localStorage. Проверка на слабой Intel iGPU и отдельный длительный тест батареи остаются за пределами этих результатов.

## Стенд

```sh
npm run dev -- --port 1437
node --test tests/*.test.mjs
```

- Большой граф: `/graph-bench.html?nodes=5000&controls=1`.
- Локальный граф: `/graph-bench.html?nodes=1000&local=1`.
- Реальные скопированные данные: `/graph-bench.html?vault=1` после `scripts/export-graph-fixture.mjs`.

Управляющие кнопки и счётчики находятся только на странице разработчика. Они не входят в production entrypoint. Файл с содержимым реальных заметок исключён из Git. Исходные и итоговые снимки счётчиков сохранены в локальных артефактах задачи в `obsidian-study/perf/global-pass`.
