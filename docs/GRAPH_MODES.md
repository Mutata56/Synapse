# Два режима графа

Последующий проход по производительности описан в [GRAPH_PERFORMANCE.md](GRAPH_PERFORMANCE.md).

Изменение сделано в отдельной ветке `codex/graph-modes`. База графа — `ac88a67`: в ней уже сохранён импорт Markdown из Obsidian. Рабочий checkout `main` используется независимо.

## Поведение

- **Объёмный** сохраняет острова папок, мягкую подсветку и цветную жидкую оболочку. Это существующий объёмный визуальный стиль на Pixi/WebGL.
- **Obsidian** показывает плоские узлы и тонкие прямые связи. Размер зависит от числа связей. Раскладка начинается с реальных компонентов связности и узлов-центров, затем расслабляется силовой симуляцией. Папки здесь не создают искусственных узлов и рёбер.
- При наличии скопированного `notes/.obsidian/graph.json` читаются правила цветов, размер узлов, толщина линий, фильтры и параметры сил. Исходный файл не меняется. Цвета и размеры, отредактированные в Synapse, сохраняются в локальных предпочтениях.
- В **Группах** можно задать цвет и запрос `path:"Папка"`, `file:"Заметка"`, `tag:#тег`, отрицание и `OR`. Первое совпадение задаёт цвет. Это поддерживаемая часть языка запросов; полная поисковая грамматика Obsidian не реализована.
- Фильтры позволяют включить теги, вложения, неразрешённые ссылки и заметки без связей. Сохраняются поиск по названию/пути, фильтр тегов и таймлайн.
- В обоих режимах одиночный клик показывает карточку узла, двойной клик или кнопка «Открыть» в карточке открывает заметку. Shift-клик фокусирует окружение, контекстное меню закрепляет узел. Колесо, перетаскивание и кнопки управляют камерой.
- Миникарта имеет ручку перемещения и кнопку сворачивания. Стрелки перемещают её, Shift ускоряет движение, Home или двойной клик возвращает в угол. Положение и свёрнутое состояние сохраняются и ограничиваются размером окна.
- Кнопки тестового заполнения и очистки убраны из интерфейса графа.

## Работа и расход ресурсов

Раньше Pixi ticker продолжал рисовать примерно 60 кадров/с даже после остановки физических расчётов. Теперь отрисовка запускается при изменении данных, камеры или взаимодействии и полностью останавливается в покое. Симуляция охлаждается до остановки таймера, при скрытии окна или потере фокуса приостанавливается. При размонтировании удаляются Worker, обработчики и ресурсы рендера.

Физика Barnes–Hut и извлечение Markdown-ссылок работают в отдельных Workers. Для packaged WKWebView используются встроенные Workers с Blob URL ([возможность Vite](https://vite.dev/guide/features.html#web-workers)). Обычный URL Worker на origin `tauri://` оказался несовместим с проверенной macOS-сборкой.

В объёмном режиме общий буфер ограничен 1,8 млн пикселей и DPR 1,5; мягкое поле — 768 тыс. пикселей. Поле обновляется по геометрии, камера остаётся отзывчивой, невидимые узлы отсекаются, подписи имеют ограниченный кэш. На каждый кадр не обновляется React-состояние.

Ссылки строятся из тел Markdown: поддержаны wiki-ссылки, embeds, обычные и reference-ссылки; код исключается. Сначала разрешается физический путь, затем относительный путь и название с учётом папки источника. Одноимённые заметки больше не выбираются произвольно по первому заголовку.

## Проверка 10 октября 2026

Хост: Apple M5, macOS 26.6.2. Локальный стенд проверен при 1200×800 и 480×800; вид на реальных заметках также сравнен с присланным референсом 1286×1168.

| Данные | Наблюдение |
|---|---|
| Старый граф: 1000 заметок + 50 папок | После остановки физики оставалось около 60 кадров/с |
| Новый объёмный граф: 1000 и 5000 заметок | После затухания — 0 кадров/с в покое |
| Новый плоский граф: 5000 заметок | Расчёт и отрисовка останавливаются в покое |
| Копия реального vault: 530 заметок | Плоский граф содержит 1488 узлов и 3912 связей с включёнными неразрешёнными ссылками; применены три исходные цветные группы |
| Desktop preview | Оба режима, переключение, загрузка скопированного vault и открытие заметки проверены в macOS-сборке |

Значения из диагностического стенда описывают кадры приложения и время CPU на их подготовку. Они не измеряют завершение GPU-команд или ватты. Проверки на слабой Intel iGPU и длительный сравнительный тест батареи ещё не выполнены; абсолютная гарантия FPS для любой видеокарты из этих результатов не следует.

13 проверок графа и 13 проверок сохранности импорта, включая чтение всех 530 заметок без изменения исходных Markdown, прошли. Production frontend и macOS `.app` собираются. Остались прежние предупреждения сборки о размере общего chunk, смешанных динамических импортах и CSS `::highlight`.

## Повторение

```sh
node --test tests/graph-modes.test.mjs tests/obsidian-import.test.mjs
npm run build
npm run dev -- --port 1437
```

Синтетический стенд: `http://127.0.0.1:1437/graph-bench.html?nodes=5000`.

Для локального сравнения с копией импортированного vault:

```sh
node scripts/export-graph-fixture.mjs /path/to/copied/notes
```

Затем открыть `http://127.0.0.1:1437/graph-bench.html?vault=1`. Экспорт читает копию и создаёт локальный `tests/fixtures/graph-vault.json`, исключённый из Git; тела заметок не входят в коммит или production-бандл. Стенд не имеет файлового SDK и при клике лишь регистрирует выбор. Для полного теста импорта используется переменная `SYNAPSE_IMPORT_NOTES_DIR` с путём к копии `notes`.

## Предварительный замер свёрнутых приложений

До изменения графа оба установленных приложения были свёрнуты и измерены в течение 120 секунд с включением их helper-процессов по macOS coalition ID.

| Приложение | Средний CPU, 100% = одно ядро | Resident memory в конце | Сеть за интервал |
|---|---:|---:|---:|
| Synapse | 0,200% | 848,8 MiB | 0 байт |
| Obsidian | 0,822% | 567,4 MiB | 0 байт |

В этом коротком замере повышенный расход интернета у Synapse не подтвердился. Его память была выше. Экраны и плагины не были приведены к одинаковому состоянию; цифры не устанавливают общее преимущество в расходе батареи. Начальный snapshot сетевых счётчиков исключён, Mach CPU ticks переведены с коэффициентом хоста 125/3. Полные сырые замеры сохранены в локальных артефактах исследования.
