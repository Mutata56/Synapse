# Iconize в Synapse

Перенос совместим с идентификаторами Iconize 2.14.7: `FabJava`, `SiPostgresql`, `LiWarehouse` и остальными. В приложении доступны 18 530 иконок из всех 13 наборов этой версии, каталог эмодзи и локальные изображения Twemoji. Интернет для выбора и отображения не нужен.

## Использование

- «Изменить иконку» в меню файла или папки открывает каталог. Доступны поиск, фильтр по набору, недавние иконки, цвет и эмодзи. В представлении «Файлы» можно назначить одну иконку всему выделению.
- Нажатие на значок заметки меняет его. «Без иконки» отключает назначение, включая правила; «Автоматически» возвращает свойства, наследование и правила.
- В «Настройки → Иконки» меняются размер, цвет, отступы, стиль эмодзи, положение относительно заголовка, значки вкладок, ссылок и текста.
- Правила сопоставляют имя или весь путь с регулярным выражением. Учитываются порядок, тип элемента и флаг включения. Для некорректного выражения применяется поиск подстроки, как в Iconize.
- Наследование папки применяется к её потомкам. Индивидуальное назначение и свойства заметки имеют приоритет. Затем учитываются наследование и первое подходящее правило.
- SVG и PNG можно добавить в собственный набор. Название создаёт совместимый с Iconize префикс; конфликты с существующими префиксами отклоняются.

## Markdown и импорт

Свойства по умолчанию — `icon` и `iconColor`; названия полей настраиваются. Поддерживаются строки в одинарных и двойных кавычках. Значки в тексте записываются как `:FabJava:` или `:SiPostgresql:`; разделитель можно поменять. В коде эти записи остаются буквальным текстом.

В блочном редакторе используются декорации ProseMirror: значок отображается, а запись остаётся обычным текстом в документе и экспорте. Когда курсор входит в запись, появляется её исходный текст. В Markdown-просмотре обрабатываются только текстовые узлы. Внутренние ссылки используют значок целевой заметки.

При первом запуске ветки Synapse читает Iconize из ранее импортированного хранилища: корень копии либо `sourceVault` в существующем `.synapse/obsidian-import.json`. Если исходный каталог недоступен, его можно выбрать кнопкой импорта. Исходный Obsidian не изменяется.

Настройки, назначения и собственные изображения хранятся в `notes/.synapse/iconize.json`. Повторный импорт сохраняет индивидуальные решения Synapse; настройки берутся из выбранного Iconize. Файл входит в обычный резервный архив Synapse. Перемещения, переименование папок, корзина и восстановление переносят назначения вместе с файлами. Сохранение атомарное; при ошибке записи прежнее состояние остаётся доступным.

## Каталог

Поставляемые наборы: Font Awesome Brands / Regular / Solid, Remix Icons, Icon Brew, Simple Icons, Lucide, Tabler Icons, Boxicons, RPG Awesome, Coolicons, Feather Icons, Octicons. Дополнительные native Lucide-идентификаторы берутся из закреплённой зависимости Synapse. Для совпадающих outline / filled имён Tabler добавляется суффикс `Filled`.

В `public/iconize/manifest.json` указаны версии, количества и SHA-256 исходных ZIP. В `public/iconize/licenses/` находятся лицензии и сведения об авторах. Нормализация имён, SVG-спрайты и `currentColor` — изменения Synapse. Логотипы принадлежат их владельцам.

Спрайты и индексы отделены от JavaScript. Пикер загружается по запросу; сетка монтирует видимые строки с запасом. Большие наборы не создают тысячи React-элементов при открытии.

Для пересборки нужен checkout исходников Iconize 2.14.7, ZIP по ссылкам из его `src/icon-packs.ts` и установленные npm-зависимости Synapse:

```sh
python3 scripts/build-iconize-catalog.py --downloads /path/to/zips --iconize-source /path/to/obsidian-iconize-2.14.7
```

Три встроенных ZIP берутся из `iconPacks/` checkout Iconize. Архив Font Awesome используется один для всех трёх вариантов. Для эмодзи нужен `twemoji.zip` версии 14.0.2. Сборка не загружает файлы сама.

## Проверки

```sh
node --test tests/*.test.mjs
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib iconize_import
```

Опционально `SYNAPSE_IMPORT_NOTES_DIR` включает проверку копии реального хранилища, а `SYNAPSE_ICONIZE_TEST_VAULT` — чтение настоящего Iconize в Rust-тесте. Браузерная страница `tests/fixtures/iconize.html` запускается с `tests/iconize.vite.config.mjs` и использует синтетические заметки и файловую систему в памяти.
