# AnuPpuccin in Synapse

AnuPpuccin · Dracula adapts the active Obsidian profile: AnuPpuccin 1.5.0, extended Dracula, the theme-controlled Flamingo accent, simple rainbow folders, colored headings and h1/h2 dividers. The theme accent overrides appearance.json's custom red accent; the visible accent is #f5bda6.

Choose **Settings → Appearance → Appearance theme → AnuPpuccin · Dracula**. The existing Synapse preset remains selectable. Old workspaces keep their original preset until explicitly changing it. Selecting a preset sets its default accent; the accent can then be customized. The preference lives with the existing workspace settings and unrelated values remain intact.

The preset imports all 26 palette values from the active Dracula profile. Its principal roles use crust #1a1b23 for the shell/code, mantle #21222c for headers/table headings, base #282a36 for the work region/editor and cream #f8f8f2 for text. Quotes use the intentional translucent Crust surface `rgba(26,27,35,.5)` with an accent rule; stronger rules use Surface 2. Filled accent controls select readable ink dynamically, including when the accent is customized. Content H1–H6 colors are red, peach, green, teal, lavender and mauve. H1/H2 dividers apply to full Markdown and Files reading and BlockNote headings; compact library/Tags readers receive heading colors while retaining their local geometry. Automatic folder colors follow the order among sibling folders, restart independently within each parent and repeat after twelve tones, including nested folders. This follows the stored tree order rather than a temporary Files sort/filter; the per-tree map is cached. Explicit folder/icon colors take precedence. The palette changes CSS and existing rendering only: it does not rewrite Markdown or recreate the editor. The capture window reads the same appearance when focused.

Implementation: src/themes/anuppuccin.css, src/lib/settings.ts, src/lib/folderTheme.ts. Inter/JetBrains Mono, the matched type scale, workspace composition, Quick Look and existing module behavior remain their owning systems. This port adapts palette and supported reading/folder roles to Synapse's UI; it does not install Obsidian plugins or import their JavaScript.
